## Descripción del proyecto
Aplicación web de una sola pantalla desarrollada con HTML5 semántico, CSS3 (Flexbox, CSS Grid y variables personalizadas) y JavaScript moderno (ES6+). Permite consultar la API pública de Rick and Morty filtrando personajes por nombre y estado vital (`Vivo`, `Muerto`, `Desconocido`), mostrando sus datos principales en tarjetas responsivas y conservando la última búsqueda mediante `localStorage`.
